Charter · pure daʿwah purposes

This workbench exists only to help Muslims and seekers design accurate, adab-first educational tools. It is not a fatwa desk, not a social network, and not a replacement for teachers or the local mosque.

  1. Source discipline — Scripture lines come only from section packs or primary links (quran.com / sunnah.com). Free-type is personal reflection only — never presented as revelation.
  2. Adab of invitation — Wisdom, good instruction, and the best manner (16:125). No argument-first content; no weak reports as authority.
  3. Privacy & offline — Drafts and progress stay on this device unless the user explicitly exports.
  4. Isolation — Lives under Craft only. Does not load Companion shell, Amānah vault, or Campus desk engines.
  5. Honesty of limits — Always stamp “Educational only — not a fatwa.” No certificates, no grades of īmān, no accreditation claims.

✦ Short tutorial · how to use this workbench

Six steps · stay educational · pure daʿwah only.

  1. Read the charter above — source discipline, adab, privacy, isolation, honesty of limits. Never skip the educational stamp.
  2. Source chips first — open the Source chips tab and pick an RRRA line. Scripture stays pack-backed or primary-linked; free-type is reflection only.
  3. Sketch the outline — App outline tab: name, audience, offline needs, screens, hard limits. Save on this device.
  4. Build in the Lab — App Building Lab tab: copy a starter prompt, open Lovable / Bolt / Grok / AI Studio / v0 / Replit / Base44, iterate, keep “educational only” in every prompt.
  5. Pack extras — Curriculum modules, reminder cards, quiz bank (feedback points to sources, never a ruling). Export JSON locally.
  6. Print / share carefully — One-pager tab → browser Print → PDF. Verify primary texts on quran.com / sunnah.com. Consult a local teacher for real questions.
