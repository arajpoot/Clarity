# NurOS Icon Pack v1

## Research cues (peer dawah UI)
- **Begin Islam**: calm multi-theme cards, beige/olive, bilingual clarity, no visual noise
- **Digital dawah / Noor-style UIs**: geometric softness, gold accents, Cormorant/Amiri for titles, clean sans for UI
- **Islamic icon systems**: worship set (ṣalāh, tasbih, Qur’an), architecture (dome/arch), lifestyle (lantern/crescent) — line weight consistent, scalable

## Pack principles
- 24px grid, ~1.75 stroke, round caps
- Colors: Nur green `#1e7d5e` · gold `#c9a84c`
- No figurative portraits / no prophet likeness
- CSS mask icons (no image host dependency)

## Icons
salah · tasbih · quran · vault · reminder · reality · reflection · action · campus · tabligh · callig · tajweed
