# M4 · Banner research (peer models) · educational

## Peer patterns observed
| Source | Pattern | Applied to Clarity Amānah |
|--------|---------|---------------------------|
| Shariawiz / MyWassiyah / Wassiyyah | Lead with faith + family protection; inheritance structure | Banner: trusts (4:58) + shares (4:7) |
| Wasiyat.in resources | Quranic refs 4:11, 4:12, 4:176 front-and-center | Links to Quran.com 4:7, 4:11, 4:12 |
| Islamic Heritage sample will | Opens with 4:58 *amānāt* | Primary Arabic line on banner |
| HalalWallet / academic primers | Order: expenses → debts → wasiyyah ≤1/3 → farāʾiḍ | Chip: “Debts before bequests” |
| ICNA / scholarly quotes | Stress justice in will; not unjust bequests | Disclaimer: not a fatwa / ask local scholar |

## Sharīʿah design choices
- **No figurative animate art** in banner (geometric lattice only).
- **Arabic + meaning** with source links (Quran.com).
- **Not a live inheritance calculator** (avoids verdict UI).
- **On-device** positioning vs commercial will platforms.

Educational only — not a fatwa.
