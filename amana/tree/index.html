💡 How to use the Family Tree · quick guide
  1. Build pedigree — add members on the main tree; set ♂/♀, ● Alive / † Deceased, and birth year on each card.
  2. ＋ Relative — link child, spouse, sibling, or parent from the searchable registry (or type a new name).
  3. 🌳 Own Family Tree — open a personal branch under the main view; siblings of the root appear without needing parents first.
  4. Family sheet / Data health — print or check missing genders & vitals before Farāʾiḍ.
  5. Privacy — data stays on this device only. Educational genealogy — not a legal pedigree certificate.
