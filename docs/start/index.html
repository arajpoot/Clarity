How to start with Clarity

Short orientation. Educational only — not a fatwa.

1. Choose a room

From the port lobby or any room’s top rail, open one door:

  • Yawm — if you want today’s portion first
  • Companion — if you want pathways and reminder sections
  • University — if you want an ordered study track
  • Craft — if you want practice desks (tajweed, calligraphy, …)
  • Amānah — if you need on-device trust notes (not legal advice)

2. Stay local-first

Much of Clarity is built to work on your device. Do not treat any screen as a ruling or a court form.

3. Verify sources

Prefer primary libraries when checking a report or āyah. See Sources.
