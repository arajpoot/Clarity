## Recommendation (yes)
Landing should present **two clear doors** without deleting admission richness:

| Path | For | Primary | Support |
|------|-----|---------|---------|
| **New seeker** | First visit | Begin admission | Charter · Orientation |
| **Returning student** | Daily return | Student portal | Seeker desk · Journey map |

Charter and Orientation stay **first-class pages** under Campus; the landing only **surfaces** them so new seekers see limits/help before depth.
