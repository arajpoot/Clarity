Sources policy

Educational only — not a fatwa. Clarity is a learning companion, not a scholarly court.

Preferred primary references

  • Quran.com — Qur’ān text and translations
  • Sunnah.com — hadith collections with numbers

How reports should appear

  • Prefer collection · number · grade when a report is shown as evidence
  • If a grade is not loaded: say so honestly and link the source page
  • Do not present machine translation as an official tafsīr

What Clarity is not

  • Not a fatwa service
  • Not a substitute for a qualified local teacher in personal cases
  • Not legal advice for wills, inheritance, or debts
