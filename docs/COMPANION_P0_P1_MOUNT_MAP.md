## P1 — Mount map

### Expected sequence
1. **shell-v1** boots → binds path + rail → `mountTab(getTab())`
2. **mount-fortify** patches `ClarityCompanionShell.mountTab` → DOM inject + script re-exec → **`clarity:tab-mounted`**
3. **content-stream** applies path×tab focus / `data-cs-path-only`
4. **Hydrators & repairs** react (tab-engines, craft, hifz, hadith, path-gov, deep-learn, housekeep, overnight, enrichment-*)
5. **path-governance** may `display:none` non-ALLOW card ids (tension with enrichment hold)
6. **enrichment-restore / overnight / nuclear** try to show cards again (race)
