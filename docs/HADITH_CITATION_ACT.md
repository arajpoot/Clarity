# Governance act — ḥadīth citation (mandatory fields)

**Bismillah.** Educational only — not a fatwa.

Every ḥadīth surface in Companion must show:
1. **Grade** (e.g. Ṣaḥīḥ / Ḥasan)  
2. **Collection** (e.g. Bukhārī, Muslim)  
3. **Number** (collection numbering; invite Sunnah.com verify)

Implemented via `companion-hadith-governance-v1.js` sample sparks + citation line.
