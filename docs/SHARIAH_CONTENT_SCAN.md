# Shariah content scan · Companion (educational)

**Bismillah.** Educational only — not a fatwa.

## Principles applied
1. **Qurʾān-first** ordering within a tab session  
2. **Graded ḥadīth** preferred; citation must carry grade · collection · number (HADITH_CITATION_ACT)  
3. **Seerah / character** support, not replace, revelation  
4. **Tools** (meme, callig, translator) are aids — never primary evidence  
5. **No content deletion** — path engine defers/reorders only  
6. **Path is not a grade of īmān** — only complexity / volume pacing  

## Tab assignment (home)
| Tab | Primary job | Source emphasis |
|-----|-------------|-----------------|
| Reminder | Commands, āyāt, ḥadīth sparks, Names | Qurʾān · ḥadīth |
| Reality | Seerah, nations, timeline | Seerah · Qurʾān stories |
| Reflection | Tawbah, night audit, character | Qurʾān · heart work |
| Action | Deeds, Hifẓ, Tajweed, Ḥajj tools | Practice · Qurʾān craft |
| Notes | On-device ledger | Private |
| About | Charter · feedback | Meta |

## Engine
`companion-nuros-path-engine-v1.js` scores cards by source × path × routine slot × local learning.
