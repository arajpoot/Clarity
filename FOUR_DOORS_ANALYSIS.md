# Four doors — analysis

## 1. Companion (`/companion/`)
**Role:** Long-path companion: phased learning tabs, banner, craft tools.
**Strength:** Largest shell; path + craft live here.
**Constraint:** Must not re-absorb daily routine (Yawm SoT) or primary Amānah UX.

## 2. Yawm (`/daily/`)
**Role:** Daily portion — one place for “what now” in the day.
**Strength:** Clear module grid; Qur’an/Sunnah-first sources.
**Constraint:** No vault crypto; link to `/amana/` for trust tools.

## 3. University (`/campus/`)
**Role:** Structured learning (desk, lab, library, portal).
**Strength:** Separate campus CSS system.
**Constraint:** Campus vault page ≠ Amānah.

## 4. Amānah (`/amana/`)
**Role:** Private, on-device trust and legacy aids.
**Strength:** Dedicated sub-routes (dayn, heirs, notes, tree, fiqh, wasiyyah).
**Constraint:** Strict labeling (not fatwa / not legal advice); room-local sealed modules.

## Lobby (`/`)
Four equal entries + `clarity-room-nav`. Story is **choose a room**, not “Companion is the whole site.”
