# Adhkār module (Companion)

Educational only — not a fatwa. Preferred windows (scholars differ):

- **Morning:** after Fajr until sunrise (wider: until near Ẓuhr if missed).
- **Evening:** after ʿAṣr until Maghrib (wider: into early night).

Content policy: Qur’an + strong reports preferred; show collection · number · grade when citing ḥadīth. Where graders differ, note “graders differ / text does not settle this.”

Local progress only. Acceptance is with Allah.
